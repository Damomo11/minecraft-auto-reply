# Damomo Auto Reply

适用于 Minecraft 26.2 的 Fabric 客户端自动回复 Mod。

## 功能

- 只能从 Mod Menu 的“配置”按钮进入设置，不添加快捷键或命令。
- 总开关，以及每条规则独立的启用开关。
- 使用 Java 正则表达式匹配聊天消息。
- 每条规则可选择“聊天文本”或“按钮事件”模式。按钮事件模式会读取系统消息中 `RUN_COMMAND` / `SUGGEST_COMMAND` 点击事件的原始命令，并且只对命令做正则匹配。
- 回复支持数字捕获组（`$1`、`$2`）和命名捕获组（`${name}`）。
- 一条规则可以包含任意数量的回复消息，命中后按消息列表顺序依次发送。
- 规则列表采用可滚动卡片，每条规则只显示摘要；编辑内容放在独立页面。
- 编辑页内置实时匹配测试和回复预览。
- 可设置 0–5000 毫秒回复延迟；回复前会再次检查总开关和规则开关。
- 忽略动作栏消息与自己的玩家聊天回显，降低循环回复风险。
- 回复以 `/` 开头时会作为命令发送。
- 配置保存在 `.minecraft/config/damomo-auto-reply.json`；旧版 `momo-chat.json` 会自动迁移。

## 示例

匹配正则：

```regex
^<([^>]+)> 你好$
```

回复内容：

```text
你好，$1！
```

命名捕获组也可以使用：

```regex
^<(?<player>[^>]+)> 有人在吗[？?]$
```

```text
在的，${player}！
```

规则使用 `find()` 匹配，因此既可以写完整消息正则，也可以只匹配消息中的关键词。规则按列表顺序检查，每次只执行第一条匹配成功的规则。该规则内的所有回复消息会按列表顺序以 350 毫秒间隔错开发送，降低服务器限流丢消息的风险。

### 按钮事件模式示例

如果服务器按钮携带的点击命令为：

```text
/msg Momo accept party_42
```

将规则切换到“按钮命令”模式，然后使用：

```regex
^/msg ([^ ]+) accept (.+)$
```

回复仍然可以引用捕获组，例如：

```text
收到 $1 的邀请，编号是 $2
```

按钮显示文字和系统消息的其他文本不会参与此模式的匹配。命令开头的 `/` 会保留。

## 构建

需要 Java 25 或更高版本：

```powershell
.\gradlew.bat build
```

输出文件位于 `build/libs/damomo-auto-reply-1.3.0.jar`。

## 运行依赖

- Minecraft 26.2
- Fabric Loader 0.19.5 或更高版本
- Fabric API 0.161.0+26.2
- Mod Menu 20.0.3
